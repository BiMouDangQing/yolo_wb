# YOLO 训练图片预处理流程

> 适用项目：duilian-yolo26（榴莲目标检测）
> 目的：说明 YOLO（ultralytics）训练前需要对图片做哪些预处理，以及白平衡等操作是否有必要。

---

## 1. 核心结论

YOLO 训练前是否需要预处理，取决于两点：

1. **数据质量**：图片是否模糊、重复、格式混乱、标注错误。
2. **训练 / 推理环境一致性**：训练集与部署时拍摄的光照、色温是否一致。

**优先级排序**（从高到低）：

```
格式统一  >  数据清洗（去重 / 剔废图）  >  标注质量  >  白平衡（可选）  >  几何 / 颜色增强（交给训练参数）
```

---

## 2. 必须做的基础处理

### 2.1 格式统一

- YOLO（ultralytics）最稳定的输入是 **JPG / PNG**。
- HEIC / HEIF / TIF 等格式需先转换为 JPG。
- 对应工具：本项目的「图片转换」模块（`QT/modules/converter.py`）。

### 2.2 数据清洗

- 删除**模糊**、**过曝**、**全黑**图片。
- 删除**重复或高度相似**的图片（避免过拟合，防止 val 集泄漏）。
- 剔除**标注框明显错误**的样本（框偏、漏标、类别标错）。

### 2.3 标注规范

- 框要贴边、不要漏标或错标。
- 类别名统一，否则会被当作不同类别。

> 标注质量比任何像素级预处理都重要。

---

## 3. 白平衡：分情况，不是必须

白平衡的作用是**消除色偏、统一色温**，避免模型把「偏黄 / 偏蓝」误当成物体特征。

### 3.1 建议做白平衡的情况

- 数据集拍摄环境色温差异大（如室内钨丝灯 vs 白天自然光混合）。
- 手机自动白平衡不稳定，同一场景颜色漂移明显。
- 部署 / 推理时的光照与训练数据明显不同。

### 3.2 可以不做的情况

- 数据来源单一、光线稳定。
- 训练时已开启 ultralytics 的颜色增强（`hsv_h` / `hsv_s` / `hsv_v` 抖动，默认开启），相当于一种「在线白平衡增强」。

### 3.3 本项目可用的算法

对应工具：本项目的「白平衡」模块（`QT/modules/white_balance.py`）。

| 算法 | 说明 | 适用场景 |
| --- | --- | --- |
| 灰度世界（Gray World） | 假设各通道均值相等，按均值缩放 | 批量统一色偏 |
| 白斑法（White Patch / Max RGB） | 以各通道最大值为参考 | 存在白色参考物的场景 |
| 完美反射（Perfect Reflector） | 以 95% 分位数为参考 | 抗高光更稳 |
| 手动增益（Manual） | 手动调整 R / G / B 增益 | 轻微偏色微调 |

> 各算法的详细原理、计算公式与适用场景，见 [`QT前端使用说明.md`](QT前端使用说明.md) 第 4 节「白平衡算法详解」。

---

## 4. 几何与颜色增强：交给 ultralytics

ultralytics 训练时自带强增强（mosaic、mixup、翻转、缩放、HSV 抖动等），因此：

- **不必手动**做旋转、翻转、缩放、颜色抖动，通过训练参数调即可。
- 手动预处理过多反而可能**引入伪影、降低泛化能力**。

---

## 5. 一条铁律：训练和推理要一致

- 如果**训练集**做了白平衡，**推理时也必须做同样的白平衡**，否则分布不一致，精度会掉。
- 如果只在推理端加白平衡而训练没做，需谨慎——训练数据里最好也包含类似的色偏样本。

---

## 6. 推荐完整流程

```
原始图（HEIC 等）
  → ① 格式统一为 JPG（图片转换模块）
  → ② 去重 + 剔除废图
  → ③ 按需做白平衡统一色温（白平衡模块，可选）
  → ④ 标注（LabelImg / CVAT / Roboflow）
  → ⑤ 切分 train / val / test（如 8:1:1）
  → ⑥ ultralytics 训练（增强交给训练参数，imgsz 按需，如 640）
```

---

## 7. 内置前端工具用法

所有预处理工具都集成在 Qt 前端中，启动方式：

```bash
cd QT
python qt.py
```

标签页顺序即推荐的处理顺序：

| 标签页 | 模块文件 | 用途 | 关键参数 |
| --- | --- | --- | --- |
| 图片转换 | `QT/modules/converter.py` | HEIC/其他格式 → JPG | 模式、保存路径、质量 |
| 白平衡 | `QT/modules/white_balance.py` | 统一色温、消除色偏 | 算法、手动 R/G/B 增益 |
| 图片去重 | `QT/modules/dedup.py` | 找重复/相似图 | 汉明距离阈值（越小越严格） |
| 废图筛选 | `QT/modules/quality.py` | 剔除模糊/过暗/过曝图 | 模糊阈值、过暗阈值、过曝比例 |
| 数据集切分 | `QT/modules/split.py` | 切分 train/val/test | 比例、labels 目录、随机种子 |
| 模型管理 | `QT/modules/model_manager.py` | 导入/管理 .pt 模型 | — |
| 模型预测 | `QT/modules/predictor.py` | 单图/文件夹推理 | 模型、置信度阈值 |

各工具补充说明：

- **图片去重**：处理方式可选「仅报告 / 移动到 `_duplicates` / 删除」；每组按文件名排序保留第一张。
- **废图筛选**：处理方式可选「仅报告 / 移动到 `_bad` / 删除」；删除类操作执行前会二次确认。
- **数据集切分**：提供 `labels` 目录时会同步切分同名 `.txt`；勾选「生成 data.yaml」会自动输出 `nc` 与 `names`；随机种子为 0 表示每次随机，其余数值可复现切分结果。

---

## 8. 结论

- **白平衡**：色温不一致时「有必要」，否则属于可选优化。
- **格式统一、去重、标注质量**三项优先级远高于白平衡。
- 建议先用原始数据跑一个 baseline，若验证集上出现颜色相关的误检，再回头补白平衡。
