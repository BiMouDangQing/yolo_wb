# QT 前端使用说明

> 项目：duilian-yolo26（榴莲目标检测图片工具）
> 本工具是一个多标签页的 Qt 桌面程序，专注于 YOLO 训练前的图片数据处理（预处理）。

---

## 1. 启动方式

- **推荐**：双击项目根目录的 `yolo_data.bat`（会自动激活 yolo_data 环境、检查依赖，并以无控制台窗口方式启动，命令终端自动关闭）。
- **手动**：在已激活 `yolo_data` 环境的终端中运行：

```bash
cd QT
python qt.py
```

---

## 2. 标签页总览

标签页顺序即推荐的处理顺序：

| # | 标签页 | 模块文件 | 用途 |
| --- | --- | --- | --- |
| 1 | 图片转换 | `QT/modules/converter.py` | HEIC/其他格式 → JPG |
| 2 | 标注转换 | `QT/modules/xml2yolo.py` | XML 标注 → YOLO txt，并筛选无标注图片 |
| 3 | 白平衡 | `QT/modules/white_balance.py` | 统一色温、消除色偏 |
| 4 | 图片去重 | `QT/modules/dedup.py` | 找出重复/高度相似图片 |
| 5 | 废图筛选 | `QT/modules/quality.py` | 检测模糊/过暗/过曝图片 |
| 6 | 过曝处理 | `QT/modules/overexposure.py` | 压暗高光、校正过曝 |
| 7 | 过暗处理 | `QT/modules/underexposure.py` | 提亮暗部、恢复细节 |
| 8 | 数据增强 | `QT/modules/augment.py` | 翻转/旋转/色彩/噪声增强，可同步标签 |
| 9 | 数据集分析 | `QT/modules/analysis.py` | 统计标注、剔除未标注、生成分析 CSV |
| 10 | 数据集切分 | `QT/modules/split.py` | 切分 train/val/test |

## 3. 各标签页用法

> 所有支持预览的标签页都提供「翻页预览」：批量处理完成后，可用「上一张 / 下一张」按钮逐张翻看结果，页码显示当前进度（如 3/100）。

### 3.1 图片转换

- 转换模式：通用图片 → JPG、HEIC/HEIF → JPG。
- 输入：单张图片或整个文件夹（递归扫描子目录）。
- 保存：指定输出目录，或勾选「替换原文件」原地转换并删除原图。
- 质量：JPG 质量 1–100，默认 95。
- 预览：批量转换后可翻页浏览每张图的「原图 / 转换结果」。

### 3.2 标注转换

把 Pascal VOC / LabelImg 的 XML 标注转成 YOLO 格式 txt：

- images 目录（必填）、xml 目录（留空=与图片同目录）、labels 目录（留空=写到 xml 旁边）。
- 无标注输出目录（留空= images 同级下的 `unlabeled`），可选「复制 / 移动」，也可跳过筛选。
- 类别 classes：留空自动收集；或填 `"durian,background"`（逗号分隔，顺序即 class_id）；或填 `classes.txt` 路径。
- 转换完成后自动生成 `classes.txt`。
- 预览：批量转换后可翻页浏览每张标注图片的带框预览。

### 3.3 图片去重

- 基于感知哈希（dHash）：对每张图计算 64 位指纹，两两比较汉明距离。
- 汉明距离阈值：0–64，越小越严格（0 表示只有完全相同才算重复），默认 5。
- 处理方式：仅报告 / 移动到 `_duplicates` 文件夹 / 删除（每组按文件名保留第一张）。
- 预览：可翻页浏览每个重复组的「保留图 / 重复图」。

### 3.4 废图筛选

- 判据：
  - 模糊：拉普拉斯方差低于阈值（默认 100，越大越严格）；
  - 过暗：平均亮度低于阈值（默认 15）；
  - 过曝：亮度 > 250 的像素比例高于阈值（默认 0.6）。
- 处理方式：仅报告 / 移动到 `_bad` 文件夹 / 删除。
- 预览：可翻页浏览所有检测出的废图及判定原因。

### 3.5 过曝处理

对过曝图片做高光压缩、降低整体亮度（对 HSV 明度通道做 gamma 压缩）。

- 校正强度：0–100，越大压暗越明显，默认 50。
- 输入：单张图片或文件夹；保存：替换原文件 / 指定输出目录 / 留空仅预览。
- 预览：批量处理后翻页浏览每张图的原图与结果。

### 3.6 过暗处理

对过暗图片提亮、恢复暗部细节（对 HSV 明度通道做 gamma 提亮 + 可选 CLAHE）。

- 校正强度：0–100，越大提亮越明显，默认 50。
- 可勾选「启用 CLAHE」增强暗部局部对比度（默认开启）。
- 输入/保存/翻页预览同过曝处理。

### 3.7 数据增强

对图片批量做数据增强，每个勾选的增强方式对每张原图生成一张新图（命名 `<原名>_<标签>.<后缀>`）。

- **几何增强**（会同步变换 YOLO 标签坐标）：水平翻转、垂直翻转、旋转 90°/180°/270°。
- **色彩与噪声增强**（标签不变，仅随图复制）：亮度、对比度、饱和度、色调偏移、高斯噪声、椒盐噪声，每项均可调参数。
- images 目录（必填）、labels 目录（可选，与图片同名的 `.txt`）、输出目录（必填）。
- 提供 labels 时，几何增强会同步生成同名 `.txt`（坐标随翻转/旋转变换）；色彩与噪声增强则复制原标签内容，使增强结果可直接用于训练。
- 预览：可翻页浏览每组「原图 / 增强结果」（最多 200 组）。

### 3.8 数据集分析

扫描 images 目录，统计标注情况与各类别框数量，可选剔除未标注图片，并生成分析 CSV。

- images 目录（必填）、labels 目录（留空=与图片同目录的 `.txt`）。
- 未标注输出目录：勾选「剔除未标注图片」后生效，留空默认 images 同级下的 `unlabeled`；可选「复制 / 移动」。
- CSV 输出：留空默认生成在 images 目录下的 `dataset_analysis.csv`，内容包含摘要（图片总数/已标注/未标注/总框数）、类别统计（class_id/类别/框数量）、图片明细。
- 类别名：逗号分隔手动指定；留空自动读 `labels/classes.txt`，否则按 class_id 显示。
- 结果：统计表格展示每个类别的框数量；无标注图片被复制/移动到指定目录。

### 3.9 数据集切分

- images 目录（必填）、labels 目录（可选，同步切分同名 `.txt`）。
- 比例：train % + val %，test 自动 = 100 − train − val。
- 模式：复制（保留原文件）/ 移动。
- 随机种子：0 表示每次随机，其余数值可复现切分结果。
- 可勾选「生成 data.yaml」，自动填 `nc` 与 `names`。
- 预览：可翻页浏览数据集示例图片（前 200 张）。

## 4. 白平衡算法详解

白平衡（White Balance）的作用是**消除色偏、统一色温**，避免模型把「偏黄 / 偏蓝」当成物体特征。其数学本质是估计场景中的**光源颜色**，再把图像校正到「标准光源」（中性灰）下。

本工具实现了 4 种算法，它们共享同一个框架——**通道独立缩放模型**（von Kries 对角模型）：

```
B' = B × kB
G' = G × kG
R' = R × kR
```

四种算法的区别只在于**增益系数 k 怎么计算**。

### 4.1 灰度世界（Gray World）

**假设**：自然场景中大量颜色的平均结果趋于中性灰，即三通道均值应相等。

**计算步骤**：

```
avgB = mean(B),  avgG = mean(G),  avgR = mean(R)
avg  = (avgB + avgG + avgR) / 3
kB = avg / avgB,  kG = avg / avgG,  kR = avg / avgR
```

**优点**：简单、快速，对整体偏色的图像效果好。

**缺点**：当画面主色调单一（大片草地、天空、红墙等）时「灰度世界」假设不成立，会引入新的偏色（例如绿色多的场景会被过度补偿而偏紫）。

> 适合：画面颜色丰富、整体性色偏的场景。

### 4.2 白斑法（White Patch / Max RGB）

**假设**：场景中最亮的点就是白色（或镜面反射），它应同时达到 R、G、B 的最大值。

**计算步骤**：

```
maxB = max(B),  maxG = max(G),  maxR = max(R)
ref  = max(maxB, maxG, maxR)
kB = ref / maxB,  kG = ref / maxG,  kR = ref / maxR
```

**优点**：场景中有白色物体或高光时效果很好。

**缺点**：对单个异常高亮像素（噪声、过曝点）非常敏感——一个坏点就能让整张图的增益失真。

> 适合：存在白色参考物或镜面高光的场景。

### 4.3 完美反射（Perfect Reflector）

**假设**：与白斑法相同（最亮区域是白色），但对噪声更鲁棒。

**计算步骤**（本工具取 95 分位数）：

```
pB = percentile(B, 95),  pG = percentile(G, 95),  pR = percentile(R, 95)
ref = max(pB, pG, pR)
kB = ref / pB,  kG = ref / pG,  kR = ref / pR
```

**优点**：用「高分位数」代替「最大值」，排除了极少数过曝/噪声像素的干扰，比白斑法更稳定。

**缺点**：分位数 p 需要根据图像调整（本工具固定为 95）。

> 适合：高光较多或存在噪声点的场景，是白斑法的改进版。

### 4.4 手动增益（Manual）

**原理**：跳过自动估计，直接由用户指定每个通道的增益系数：

```
B' = B × kB,  G' = G × kG,  R' = R × kR
```

**优点**：完全可控、可复现，适合已知偏色规律或需要精细微调的场景。

**缺点**：依赖经验判断。

> 适合：轻微偏色微调，或已知相机/光源固定偏色的批量校正。

### 4.5 算法对比

| 算法 | 参考依据 | 鲁棒性 | 适用场景 |
| --- | --- | --- | --- |
| 灰度世界 | 三通道均值 | 中 | 颜色丰富、整体偏色 |
| 白斑法 | 各通道最大值 | 低（怕噪点/过曝） | 有白色参考或高光 |
| 完美反射 | 各通道 95 分位数 | 高 | 高光多、有噪声 |
| 手动增益 | 用户指定 | 取决于人 | 微调、固定偏色 |

### 4.6 白平衡标签页操作

1. 选择**算法**；选择「手动增益」时，下方 R/G/B 增益输入框才生效（范围 0.1–3.0，默认 1.0）。
2. 选择**输入路径**：单个图片文件或文件夹。
3. 选择保存方式：勾选「替换原文件」原地覆盖，或填写「保存路径」输出到目录；留空则单张图仅预览不保存。
4. 点击「开始处理」，左侧预览原图、右侧预览结果，下方日志显示每张图的处理状态。

## 5. 常见问题

- **双击 bat 无窗口弹出？** 在终端手动运行 `python QT\qt.py` 查看报错，常见为依赖缺失。
- **删除/移动操作误伤？** 去重和废图筛选的「删除」前都有二次确认；建议先用「仅报告」模式跑一遍。
- **切分后标签数量对不上？** 检查 labels 目录中是否每张图都有同名 `.txt`，缺失会在日志中提示。
