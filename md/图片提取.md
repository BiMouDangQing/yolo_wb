# 图片提取

把一个**多层嵌套文件夹**里的图片提取到目标文件夹，解决"图片分散存放在很多子文件夹里、需要收集到一起"的问题。

- 前端标签页：**图片提取**（`QT/modules/extract.py`）
- 命令行脚本：`tools/extract_images.py`
- 模块配置节：`extract`（见 `config/`）

---

## 适用场景

```
A/
├── 2024-01/
│   ├── 相机1/
│   │   ├── IMG_001.jpg
│   │   └── IMG_002.jpg
│   └── 相机2/
│       └── IMG_003.jpg
└── 2024-02/
    └── photo/
        └── IMG_004.jpg
```

需要把上面所有图片收集到 `out/` 一个文件夹里，就使用本功能。

---

## 快速开始

### 前端

1. 打开「图片提取」标签页。
2. 选择**源文件夹**（含多层子文件夹）与**目标文件夹**。
3. 按需勾选「同时提取标签」「保留子文件夹结构」「移动」等选项。
4. 点「开始提取」。

### 命令行

```bash
# 1) 扁平提取所有图片到 out（默认，递归子文件夹）
python tools/extract_images.py -i ./A -o ./out

# 2) 同时提取同名标签
python tools/extract_images.py -i ./A -o ./out --with-labels

# 3) 保留原有子文件夹结构
python tools/extract_images.py -i ./A -o ./out --keep-structure

# 4) 同名冲突时加父文件夹名前缀 + 移动文件
python tools/extract_images.py -i ./A -o ./out --conflict prefix --move

# 5) 指定标签目录（图片与标签分开存放时）
python tools/extract_images.py -i ./A -o ./out --with-labels -l ./labels
```

## 参数表

| 参数 | 前端控件 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--src` / `-i` | 源文件夹 | 必填 | 源文件夹，可含任意层级子文件夹 |
| `--out` / `-o` | 目标文件夹 | 必填 | 提取到的目标文件夹 |
| `--no-recursive` | 递归子文件夹（取消勾选） | 递归 | 只扫描顶层，不递归子文件夹 |
| `--keep-structure` | 保留子文件夹结构 | 关闭 | 关闭=扁平输出；开启=按原始相对路径镜像 |
| `--conflict` | 同名冲突 | `rename` | `rename`=自动加序号；`skip`=跳过；`prefix`=加父文件夹名前缀 |
| `--with-labels` | 同时提取标签 | 关闭 | 一并提取同名标签 |
| `--labels` / `-l` | 标签目录 | 空 | 标签目录；留空则只在图片同目录查找 |
| `--move` | 移动（默认复制） | 关闭 | 开启后为移动文件，原文件夹中的图片被移除 |

## 输出说明

### 扁平输出（默认）

所有图片铺平到目标文件夹一层：

```
out/
├── IMG_001.jpg
├── IMG_001.txt      # --with-labels 时
├── IMG_002.jpg
├── IMG_003.jpg
└── IMG_004.jpg
```

### 保留结构（`--keep-structure`）

按原始相对路径镜像：

```
out/
├── 2024-01/
│   ├── 相机1/
│   │   ├── IMG_001.jpg
│   │   └── IMG_002.jpg
│   └── 相机2/
│       └── IMG_003.jpg
└── 2024-02/
    └── photo/
        └── IMG_004.jpg
```

### 同名冲突处理

假设有两个同名 `a.jpg`：

| 策略 | 结果 |
| --- | --- |
| `rename`（默认） | `a.jpg` + `a_1.jpg` |
| `skip` | 只提取第一张，其余跳过（计入「跳过」） |
| `prefix` | `sub1_a.jpg` + `sub2_a.jpg`（加父文件夹名前缀） |

### 完成汇总

```
完成：提取 4 张，跳过 0 张，失败 0 张，标签 2 个，缺标签 2 张
目标文件夹：out
```

## 标签查找顺序

勾选「同时提取标签」时，按以下顺序为每张图片查找标签（扩展名 `.txt` / `.json` / `.xml` / `.yaml` / `.yml` / `.csv`）：

1. 与图片**同目录**、同名的标签文件（images 与 labels 混放）
2. `--labels` 指定目录下按**相对路径**同名（去掉 images 层级）
3. `--labels` 指定目录下按**文件名**同名

## FAQ

**Q：目标文件夹可以和源文件夹相同吗？**
A：不可以，工具会拒绝（避免自我覆盖）。请指定一个不同的目标文件夹。

**Q：移动模式（`--move`）危险吗？**
A：会从原位置移除文件。建议先用复制模式验证结果，确认无误后再用移动模式。

**Q：标签和图片不在同一目录怎么办？**
A：用 `-l/--labels` 指定标签目录，工具会按相对路径/文件名匹配。

**Q：为什么有的图片「缺标签」？**
A：该图片在图片同目录与标签目录中都找不到同名标签文件。请确认标签是否存在，或标注文件扩展名是否在支持列表内。

**Q：支持哪些图片格式？**
A：`.JPG` `.JPEG` `.PNG` `.BMP` `.WEBP` `.TIF` `.TIFF` `.GIF` `.HEIC`。
