# 项目结构说明

> 说明：本项目的代码组织约定——每个数据处理功能按「前端模块 + 命令行脚本 + 文档」三处一一对应，
> 便于查找与维护。本页是唯一的结构索引，新增功能时请同步更新。

---

## 1. 目录总览

```
yolo_data/
├── run.py                  # 启动入口：把 QT 目录加入 sys.path 后调用 qt.main()

├── QT/                     # 前端（PySide6 / PyQt6 / PyQt5 回退）
│   ├── qt.py               # 主程序：import 各模块并挂载为标签页
│   ├── qt_binding.py       # Qt 绑定选择（勿改动，统一从这里 import Qt）
│   └── modules/            # 每个功能一个模块文件（算法 + 后台线程 + 页面）
│       ├── _preview.py     # 通用翻页预览组件（内部使用，不作为标签页）
│       ├── converter.py    # 图片转换
│       ├── xml2yolo.py     # 标注转换
│       ├── white_balance.py# 白平衡
│       ├── dedup.py        # 图片去重
│       ├── quality.py      # 废图筛选
│       ├── overexposure.py # 过曝处理
│       ├── underexposure.py# 过暗处理
│       ├── augment.py      # 数据增强
│       ├── analysis.py     # 数据集分析
│       ├── split.py        # 数据集切分
│       └── __init__.py
├── tools/                  # 命令行脚本（独立可运行，不依赖 Qt）
│   ├── jpg.py              # 通用图片 → JPG
│   ├── heic2jpg.py         # HEIC/HEIF → JPG
│   ├── xml2yolo.py         # XML 标注 → YOLO txt
│   ├── overexposure.py     # 过曝校正
│   ├── underexposure.py    # 过暗校正
│   ├── augment.py          # 数据增强（与前端模块算法一致）
│   └── analysis.py         # 数据集分析（统计标注/剔除未标注/生成 CSV）
└── md/                     # 使用与结构文档
    ├── QT前端使用说明.md
    ├── YOLO训练图片预处理流程.md
    └── 项目结构说明.md      # 本文件
```

## 2. 功能 → 文件 对应表

| 功能 | 前端模块 `QT/modules/` | 命令行脚本 `tools/` | 说明 |
| --- | --- | --- | --- |
| 图片转换 | `converter.py` | `jpg.py` + `heic2jpg.py` | HEIC/其他格式 → JPG |
| 标注转换 | `xml2yolo.py` | `xml2yolo.py` | XML 标注 → YOLO txt |
| 白平衡 | `white_balance.py` | （暂缺） | 灰度世界/白斑/完美反射/手动增益 |
| 图片去重 | `dedup.py` | （暂缺） | 感知哈希（dHash）去重 |
| 废图筛选 | `quality.py` | （暂缺） | 模糊/过暗/过曝检测 |
| 过曝处理 | `overexposure.py` | `overexposure.py` | 高光压缩 |
| 过暗处理 | `underexposure.py` | `underexposure.py` | 暗部提亮 |
| 数据增强 | `augment.py` | `augment.py` | 翻转/旋转/色彩/噪声，同步标签 |
| 数据集分析 | `analysis.py` | `analysis.py` | 统计标注、剔除未标注、生成 CSV |
| 数据集切分 | `split.py` | （暂缺） | 切分 train/val/test |

> 约定：新功能应同时提供「前端模块」与「命令行脚本」，二者算法保持一致；
> 尚未提供 CLI 的功能标注为「暂缺」，后续可补齐。

## 3. 新增一个功能的标准步骤

以「数据增强」为例，新增功能 `xxx` 需要改动以下 4 处：

1. **前端模块**：新建 `QT/modules/xxx.py`
   - 定义 `XxxWorker(QtCore.QThread)`：后台处理，用 `log / previews / finished` 信号回传；
   - 定义 `XxxModule(QtWidgets.QWidget)`：页面，类属性 `MODULE_TITLE = "..."`；
   - 复用 `modules._preview.PreviewBrowser` 做翻页预览；
   - 从 `qt_binding` 导入 Qt（勿直接 import PySide/PyQt）。

2. **命令行脚本**：新建 `tools/xxx.py`
   - 独立可运行（不依赖 Qt），实现与前端模块一致的算法；
   - 用 `argparse` 提供 `-i/--input`、`-o/--output` 等参数。

3. **挂载到主界面**：编辑 `QT/qt.py`
   - `from modules.xxx import XxxModule`；
   - 在 `MainWindow.__init__` 里 `self.add_module(XxxModule())`（按处理流程顺序插入）。

4. **更新文档**：
   - `md/QT前端使用说明.md`：标签页总览表 + 用法章节；
   - `md/项目结构说明.md`：目录树 + 对应表。

## 4. 模块内约定

- **图片读写**：统一用 `imread_unicode` / `imwrite_unicode`（支持中文路径，见 `converter.py` / `augment.py`）。
- **后台线程**：耗时处理放 `QThread`，UI 线程只负责发信号、收缩略图（numpy 数组），不在子线程创建 QPixmap。
- **预览**：缩略图统一用 `make_thumb_bgr`（BGR 图）或 `make_thumb_rgb`（PIL 图）转 RGB numpy。
- **标签同步**：涉及几何变换的功能（如数据增强）需同步变换 YOLO 标签，见 `augment.py` 的 `transform_yolo_line`。
